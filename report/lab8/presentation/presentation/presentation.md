# Построение туннеля IPv6–IPv4

## Постановка задачи

Заданы две IPv6-сети и IPv4-сеть. Требуется организовать туннель IPv6 поверх IPv4, позволяющий передавать данные из одной IPv6-сети в другую IPv6-сеть через сеть IPv4. Назначаемые устройствам сети адреса указаны в табл. 8.3

При организации туннеля IPv6 поверх IPv4 трафик 6in4 отправляется внутри пакетов IPv4, в заголовках которых номер протокола IP имеет значение 41. Накладные расходы инкапсуляции состоят в том, что размер заголовка IPv4 имеет размер 20 байт, соответственно при MTU в 1500 байт IPv6-пакеты размером 1480 байт можно отправлять без фрагментации.

Инкапсуляция IPv6 в IPv4: Виден успешный обмен ICMPv6 ping-пакетами между 1002::a (PC2) и 1000::a (PC1)

Протокол 41: В заголовке IPv4 указан протокол 41, что подтверждает инкапсуляцию IPv6

TTL/Hop Limit:
- Внешний IPv4 заголовок: TTL=64
- Внутренний IPv6 заголовок: Hop Limit уменьшается с 63 до 61

Адреса туннеля:
- Исходный: 10.0.0.1 (R1)
- Конечный: 20.0.0.2 (R3)
